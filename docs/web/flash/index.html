Requirements

  • Chrome, Edge, or another Chromium-based browser with Web Serial support.
  • A USB data cable and direct serial access to the board.
  • ESPHome for Home Assistant, Native for BLE/MQTT, or Matter for controller-based commissioning.

Frontend Notes

  • ESPHome: published images use the default Classic detector. After flashing, provision Wi-Fi via BLE, USB, or captive portal and then wait for Home Assistant discovery.
  • Native: provision Wi-Fi and MQTT over BLE. The Game is one example of a web integration that uses the native BLE surface.
  • Matter: after flashing, use Read Matter QR, then commission the device with a Matter controller. A full flash erase creates a new QR; normal updates preserve it.
  • Streamer and ESPHome ML: build locally from source; they are not published as separate binaries.
  • Updates: ESPHome Device Builder compiles updates after adoption; Native OTA images are published on GitHub Releases.

Fallback

If Web Serial is unavailable or your browser blocks the installer, use the download button and flash manually with your preferred ESP32 tool.
