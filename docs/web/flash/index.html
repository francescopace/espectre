Matter Pairing

ESPectre creates one onboarding identity on the device and preserves it across normal browser and CLI flashes. After flashing, reconnect to the serial port to read the same QR code at any time.

Select the same USB port used for flashing. If no data appears, press the board reset button once.

Requirements

  • Chrome, Edge, or another Chromium-based browser with Web Serial support.
  • A USB data cable and direct serial access to the board.

Frontend Notes

  • ESPHome: for Home Assistant integration.
  • Native: for MQTT and BLE native firmware. Use this to play The Game.
  • Matter: For Google Home, Apple Home, SmartThings, and Matter compatible controllers.

Fallback

If Web Serial is unavailable or your browser blocks the installer, flash from the repository CLI. See the setup guide or the CLI documentation.
