How motion detection works

ESPectre converts changes in Wi-Fi Channel State Information into a movement score and motion state on the ESP32.

The signal path

Each received Wi-Fi packet provides Channel State Information (CSI): amplitude and phase measurements across OFDM subcarriers. ESPectre keeps a stable subset and turns temporal change into detector inputs.

Why movement is visible

Multipath

Radio energy reaches the receiver over many reflected paths. A moving body changes some of those paths.

Change over time

A single CSI frame is not the answer. The useful signal is how selected subcarriers evolve across consecutive packets.

Local processing

The detector runs on the ESP32 and publishes derived values instead of raw images, audio, or cloud recordings.

Signal conditioning

Raw CSI includes gain changes, outliers, and high-frequency noise. The shared pipeline makes the detector input more stable before it decides whether motion occurred.

Normalization

Compensates for receiver gain changes so the score follows the channel rather than automatic gain control.

Hampel filtering

Rejects isolated outliers without flattening sustained motion.

Low-pass filtering

Reduces rapid noise while preserving the slower variation caused by nearby movement.

Two detector paths

Classic detector

Fuses profile displacement and temporal turbulence into a motion probability on a shared 0.0–1.0 scale. Startup calibration learns a quiet baseline and adapts the threshold. This path is transparent, lightweight, and the default in published ESPHome images.

ML detector

Extracts a compact six-feature window and runs a small on-device model. It is useful for learned decision boundaries and remains available in supported local builds.

Calibration matters

At startup, ESPectre needs a quiet reference. Placement, packet rate, nearby interference, and room geometry all affect the baseline.

  • Keep the monitored area still during startup calibration.
  • Place the board where people cross several reflected signal paths.
  • Avoid enclosing the antenna in metal or placing it directly against a large conductive surface.
  • Treat the movement score as a room-specific signal, not an absolute physical unit.
Wi-Fi sensing detects changes in the radio environment. It does not identify people, guarantee occupancy, or replace a safety-certified presence sensor.
