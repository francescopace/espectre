Flash firmware and configure Wi-Fi

Install a published ESPectre image and complete the network setup for ESPHome, Native, or Matter.

Before you begin

Supported board

Use an ESP32, ESP32-C3, ESP32-C5, ESP32-C6, or ESP32-S3 board with a data-capable USB cable.

Compatible browser

Browser flashing requires a Chromium-based browser with Web Serial support.

2.4 GHz Wi-Fi

Have the SSID and password ready. ESP32 provisioning uses a 2.4 GHz network.

Choose your firmware

ESPHome

The fastest route to Home Assistant, with automatic discovery and configurable entities.

Native

Standalone firmware with BLE provisioning, MQTT telemetry, and browser tools.

Matter

Commission an occupancy sensor into a compatible Matter ecosystem.

Flash in four steps

  1. Connect the board

    Plug the ESP32 into your computer over USB and close any serial monitor using the port.

  2. Select firmware and chip

    Open the web flasher, choose ESPHome, Native, or Matter, and select the matching ESP32 family.

  3. Install

    Choose the serial port, approve the browser prompt, and keep the cable connected until verification completes.

  4. Provision

    Continue with the frontend-specific network flow below.

Provision the connection

ESPHome

Use the ESPHome browser provisioning flow to configure Wi-Fi. Home Assistant should discover the device after it joins the network.

Native

Open Configure, connect over Bluetooth, and save the Wi-Fi and MQTT settings.

Matter

Read the device QR from the web flasher, then add it from your Matter controller. Normal reflashing preserves its onboarding identity.

Common setup problems

No serial port

  • Use a data-capable USB cable.
  • Try another USB port.
  • Close serial monitors and reconnect the board.

Device will not join Wi-Fi

  • Confirm the network is 2.4 GHz.
  • Move the board closer to the access point.
  • Repeat provisioning with the exact SSID and password.

Native is not publishing

  • Verify MQTT host and credentials in Configure.
  • Use the MQTT Monitor to check telemetry.

Matter commissioning times out

  • Keep the board close to the controller.
  • Make sure Bluetooth is enabled.
  • Reopen the commissioning window and retry.
