For a custom product frontend

Start from the quick guide and use Native or Matter as the lifecycle reference. At minimum, your adapter must:

  1. Configure and start

    Pass a RuntimeConfig to RuntimeFrontendController after Wi-Fi is ready.

  2. Keep the loop moving

    Call loop() continuously from the task that owns the runtime.

  3. Map events into product behavior

    Publish motion only from a ready snapshot, and read the controller's automatically cached snapshot for later status requests.

Need only the detector? Include espectre_core_sdk.h. The core-only path is intentionally advanced; follow csi_pipeline.cpp for normalization, evaluation cadence, and hit filtering before replacing the runtime.
