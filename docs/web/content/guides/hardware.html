Choose your hardware

ESPectre supports six ESP32 chip families. A small board is usually enough for a dedicated sensor.

Espressif ranks CSI performance as C5 > C6 > C3 ≈ S3 > ESP32, without saying how it measured it, and does not rank the S2. Treat it as a vendor ranking, not a measurement. RX sensitivity is the receiver's typical datasheet value at HT20 MCS0 (VHT20 MCS0 for the C5 on 5 GHz). The module, antenna, board layout, band, and placement still change real sensing performance.

What matters

  • The antenna: a board with an external antenna connector (U.FL/IPEX) lets you place the antenna where it works best. This helps when the case, the mounting spot, or the distance makes the built-in antenna hard to position.
  • The power supply: use a stable supply rated for the board; USB boards usually expect 5 V. If readings stay erratic in a good position, try another power adapter.
  • The placement: keep the sensor out of metal cabinets and, if the room allows it, start 3–8 m from the access point. See the placement guide.
  • The programming connection: if the board has USB, flash it with a data cable. Some very small boards need a serial or JTAG adapter instead.
