DETECTION PROFILES · 4 MIN READ

Choose your detection profile

ESPectre has two motion detectors: Lightweight Detection and High-Accuracy Detection. Both read the same Wi-Fi CSI and report the same motion state. Lightweight is the default and uses less CPU and memory. High Accuracy uses a small pretrained model to detect better, and works better in rooms it was not tuned for.

Two built-in detectors

PUBLISHED DEFAULT

Lightweight Detection

Leaves more CPU and memory for the rest of the firmware. It adapts its threshold to the room during a short calibration at startup, while the room is quiet.

lightweight

DETECTION QUALITY

High-Accuracy Detection

Uses more signal features and a small neural network. It is more accurate in our tests, including in rooms it has never seen, and needs no calibration.

high_accuracy

Choose in thirty seconds

  • Choose Lightweight when the chip is small or also runs a display, Matter, updates, or other services.
  • Choose High Accuracy when fewer false alarms and better detection matter most.
  • If unsure, keep Lightweight, then try High Accuracy in the same spot and compare.

What changes

Runtime cost

Lightweight

Less CPU and memory.

High Accuracy

More CPU and memory for the extra features and the neural network.

Detection quality

Lightweight

Good baseline; lower accuracy, and less consistent from room to room.

High Accuracy

Higher accuracy, and more consistent from room to room in our tests.

Startup

Lightweight

Calibrates its threshold in about ten seconds with the room still.

High Accuracy

No calibration; it starts as soon as it has collected enough CSI.

Training required from you

Lightweight

None.

High Accuracy

None; the model is included in the firmware.

Best fit

Lightweight

Small chips, or products that need resources for other features.

High Accuracy

Products where detection quality comes first and there is room for the extra cost.

At startup: keep the room still while Lightweight calibrates, and recalibrate after moving the sensor. High Accuracy needs no calibration, but it still needs a few seconds of CSI before it starts.

These are detector choices, not power modes. We measure each detector's CPU and memory use, but make no claim about the device's total power use.

How to select it

Pick your firmware type. You can change the profile while the device runs, and the choice is saved. On Matter, this setting is available over Direct HTTP, not through the standard Matter controls.

Native MQTT shell

Connect to the broker and select the device. The change applies at once and survives reboots:

./espectre mqtt --broker 192.168.1.20
espectre> update_sensing detector=high_accuracy
espectre> info

Use update_sensing detector=lightweight to switch back.

Home Assistant shows a detector selector, and the choice is saved. In YAML, detection_algorithm sets the profile to use until you pick one:

espectre:
  detection_algorithm: lightweight  # or high_accuracy

Published Matter images start with Lightweight. Open Live motion to switch profile; the change applies at once and survives reboots. Your own builds can also set the starting profile in the ESP-IDF configuration.

Set the detector in the runtime configuration before starting ESPectre:

espectre::RuntimeConfig config;
config.detection_algorithm = espectre::DetectionAlgorithm::HIGH_ACCURACY;
