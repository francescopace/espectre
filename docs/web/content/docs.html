Build with the SDK

ESPectre is reusable source code first, with published SDK bundles that package the same shared C++ layers for repeatable installation. You still embed the shared runtime contracts into your own ESP-IDF firmware, but the site now exposes the current stable and snapshot bundles directly.
Available under GPLv3 for open-source projects, or with commercial licensing for closed-source products.

# CMakeLists.txt
include(${CMAKE_CURRENT_LIST_DIR}/path/to/espectre/src/cpp/espectre_sources.cmake)

idf_component_register(
  SRCS
    main.cpp
    ${ESPECTRE_CORE_SOURCES}
    ${ESPECTRE_RUNTIME_ESP_IDF_SOURCES}
  INCLUDE_DIRS
    .
    ${ESPECTRE_SHARED_INCLUDE_DIRS}
)

// add optional source groups for BLE, MQTT, provisioning, or OTA as needed
// main.cpp - one include reaches the whole supported surface
#include "espectre_sdk.h"

class ProductFrontend : public espectre::IRuntimeListener {
 public:
  bool setup() { runtime_.set_config(espectre::RuntimeConfig{}); return runtime_.setup(this); }
  void loop() { runtime_.loop(); }

  void on_motion_state_changed(const espectre::RuntimeSnapshot& s) override {
    if (s.ready_to_publish) publish(s.motion_state);
  }

 private:
  espectre::RuntimeFrontendController runtime_;
};

Published SDK channels now mirror the firmware release model: stable for official releases, snapshot for the rolling main preview, and snapshot-dev on GitHub only for develop. Every bundle includes espectre_sources.cmake, the PlatformIO manifest in src/cpp/library.json, and the component-shaped root under src/cpp/. For ESP-IDF builds, the optional source groups remain ESPECTRE_RUNTIME_ESP_IDF_BLE_SOURCES, ESPECTRE_RUNTIME_ESP_IDF_MQTT_SOURCES, ESPECTRE_RUNTIME_ESP_IDF_PROVISIONING_SOURCES, and ESPECTRE_RUNTIME_ESP_IDF_OTA_SOURCES.
