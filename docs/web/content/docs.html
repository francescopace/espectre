Build with the SDK

ESPectre is reusable source code, not a precompiled binary SDK. Today you embed the shared C++ layers into your own ESP-IDF firmware through the same runtime contracts used by the Native, Matter, and Streamer frontends.
Available under GPLv3 for open-source projects, or with commercial licensing for closed-source products.

# CMakeLists.txt
include(${CMAKE_CURRENT_LIST_DIR}/path/to/espectre/src/cpp/espectre_sources.cmake)

idf_component_register(
  SRCS
    main.cpp
    ${ESPECTRE_CORE_SOURCES}
    ${ESPECTRE_RUNTIME_ESP_IDF_SOURCES}
  INCLUDE_DIRS
    .
    ${ESPECTRE_SHARED_INCLUDE_DIRS}
)

// add optional source groups for BLE, MQTT, provisioning, or OTA as needed

The web docs now describe the SDK surface that exists in the repository today. Prebuilt SDK archives are not currently published on this site, so integration happens from source through espectre_sources.cmake or the PlatformIO package manifest in src/cpp/library.json. For ESP-IDF builds, the optional source groups are ESPECTRE_RUNTIME_ESP_IDF_BLE_SOURCES, ESPECTRE_RUNTIME_ESP_IDF_MQTT_SOURCES, ESPECTRE_RUNTIME_ESP_IDF_PROVISIONING_SOURCES, and ESPECTRE_RUNTIME_ESP_IDF_OTA_SOURCES.
