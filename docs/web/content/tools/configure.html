Device settings

Connect to an ESPectre on the same Wi-Fi network to rename it, check its connection, or set up Home Assistant.

Manage a device on your local network

Device settings connects directly to a compatible ESPectre. From one page you can rename the sensor, inspect its current Wi-Fi link, choose a preferred mesh access point, configure MQTT, and check for firmware updates.

Configuration requests travel between this browser and the device. Saved MQTT credentials remain write-only: the page can replace or remove them, but it does not read the stored values back.
