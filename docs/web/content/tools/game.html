Run with the Spectre

Move to fly, stay quiet to descend, and steer the Spectre through the course.

Control the game with motion

The game turns ESPectre’s motion state into a simple flight control: movement sends the Spectre upward, and a still room lets it descend. Distance earns points, and collected orbs add bonuses.

Connect a device on the local network, or start in demo mode and use the pointer, Space, or Arrow Up. The movement threshold on this page affects only the game.
