Turn movement into sound

The theremin maps the current movement score to pitch. Larger changes in the Wi-Fi channel raise the note, while a still room becomes quiet. You can connect a local ESPectre device or use simulated motion in demo mode.

Sound is generated only after you press the start button. The tool offers sine, triangle, and sawtooth waveforms and does not need a microphone.
