Install ESPectre

Connect an ESP32 over USB to update, replace, or configure its ESPectre firmware.

Install from your browser

The installer detects a supported ESP32 and its current ESPectre firmware over USB. It can update the installed firmware without removing device data, replace it with another firmware type, or retrieve a Matter device's persisted setup code.

Use a Chromium-based browser and a USB data cable. The serial connection stays open only while the installer is active.
