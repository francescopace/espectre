Connect your board over USB, choose a firmware type, and start the installation.

Install from your browser

The installer detects a supported ESP32 over USB, matches it to the selected ESPectre frontend, and writes the corresponding factory image. Stable, preview, and development channels remain separate, so you can choose between a published release and an upcoming build.

Use a Chromium-based browser and a USB data cable. The serial connection stays open only while the installer is active; after installation, continue with the setup guide to connect the device to Wi-Fi.
