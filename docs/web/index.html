Simple Configuration

Use ESPHome for the fastest Home Assistant path, or choose another v3 frontend.

espectre.yaml 
esp32:
  variant: ESP32C6  # or S3, C3, C5...
  framework:
    type: esp-idf

external_components:
  - source:
      type: git
      url: https://github.com/francescopace/espectre
      path: src/cpp/frontend/esphome
    components: [espectre]

Why ESPectre?

A different approach to presence detection

Through-Wall Detection

Wi-Fi signals pass through walls and furniture. Detect motion in areas cameras can't see.

Privacy First

No images, no audio. Only anonymous radio signal characteristics. GDPR-friendly by design.

Home Assistant Native

ESPHome remains the polished production path for Home Assistant users.

ESP32 Powered

Runs on ESP32-S3, C6, C5, C3, and classic ESP32. Pick your favorite.

Shared Detectors

Classic and ML detector paths share the same runtime foundation across supported frontends.

Research Ready

Multi-frontend platform: C++ for production firmware, Python for R&D and algorithm development.

ESPectre Platform

Shared C++ sensing runtime with ESPHome, native BLE/MQTT, Matter, and streamer firmware paths.

Micro-ESPectre (Python)

Python/MicroPython R&D tooling for algorithm prototyping, validation, and data collection.

100% Open Source

Fully open source under GPLv3. You know exactly what's going on.
