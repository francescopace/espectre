Detect motion without cameras or microphones, then use ESPHome, Matter, native BLE/MQTT, or reusable sensing layers in your own firmware.

Flash Firmware Setup Guide

How It Works

Wi-Fi signals bounce around a room. When someone moves, those reflections change. ESPectre reads Channel State Information (CSI) from an ESP32 and turns those tiny radio-channel changes into motion and movement-score signals.

Get Started

The fastest path is the browser flasher. No local toolchain required.

1

Flash

Open Flash Firmware in a Chromium-based browser and pick ESPHome, Native, or Matter for your ESP32 board.

2

Configure

Follow the on-screen Wi-Fi setup. For Native, use Configure over BLE to provision Wi-Fi and MQTT.

3

Use it

ESPHome joins Home Assistant automatically. Matter pairs with your controller. Native works with MQTT Monitor and custom clients.

4

Go deeper

Follow the setup guide, learn how detection works, or explore the interactive demos below.

Why ESPectre?

Motion sensing without cameras, microphones, or dedicated radar hardware.

Beyond Line of Sight

Radio-channel changes can reveal motion around furniture and across some interior boundaries, where cameras cannot see.

Privacy First

Derived radio-channel measurements are processed on-device, without recording images or audio.

Home Assistant Ready

Flash ESPHome from the browser, then adopt the device in Home Assistant.

Matter Path

Published Matter firmware opens the door to Apple Home, Google Home, Alexa, and other controllers.

Native BLE / MQTT

Standalone firmware with web tools for provisioning, telemetry, and OTA, without Home Assistant.

Built to Be Reused

Shared sensing, runtime, and frontend layers support custom firmware and device integrations. Everything is open source under GPLv3.

From One Sensor to a Sensing Platform

ESPectre is useful today as a standalone motion sensor. Its roadmap grows the same privacy-first foundation into a modular, multi-device sensing system.

Release candidate · v3

Modular Sensing

A shared core and runtime power ESPHome, Matter, Native, and Streamer frontends for smart homes, research, and custom products.

Planned · v4

Web Orchestration

An optional web layer will coordinate multiple nodes with secure onboarding, room views, history, alerts, and remote management.

Exploratory · v5

Standards-Ready

The platform is designed to adopt practical IEEE 802.11bf Wi-Fi Sensing hardware while keeping its frontends, protocol, and tooling stable.

The planned web layer remains local-first and is intended to support local, self-hosted, and future managed deployments. Explore the roadmap on GitHub.

What Can You Build?

Use motion and movement-score signals in practical automations, interactive experiences, and radio-channel experiments.

Motion-Triggered Lighting

Turn on a light when movement is detected, then switch it off after the room has been quiet for a chosen period.

Room-Aware Climate

Use sustained inactivity as one input for reducing heating or cooling in an unused room.

Home Motion Alerts

Send a Home Assistant or MQTT notification when movement is detected while nobody is expected at home.

The Game

Use real Wi-Fi motion sensing as the controller for a reaction game.

Theremin

Turn live Bluetooth movement telemetry into an interactive instrument.

Radio Environment Research

Inspect CSI and signal-quality changes to explore how nearby devices, activity, and interference affect the Wi-Fi channel.
