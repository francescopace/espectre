How it works

Wi-Fi signals bounce around a room. When someone moves, the reflections change. ESPectre measures that.

01

Flash an ESP32

Plug the board into USB and install the firmware right here — no toolchain, no downloads.

02

It reads the channel

The device samples Channel State Information (CSI) and turns tiny radio changes into a motion score, on-device.

03

It publishes events

That score becomes a sensor your home already understands. Motion in, automation out.

What you get either way

The same two guarantees hold whether you flash a board tonight or ship ESPectre inside a product.

Private by physics

There is nothing to record. The device measures how the radio channel changes, computes the motion score itself, and publishes only that score — the raw CSI stays on the device.

Open source, all the way down

Firmware, the shared C++ core, and the tooling are open source on GitHub under GPLv3. Building a commercial product? A separate commercial license is available.
