PRIVATE BY DESIGN

Motion sensing without cameras or microphones.

ESPectre reads changes in the Wi-Fi channel. It does not capture images, record sound, or need a person to carry a device.

See how Wi-Fi sensing works →
01

Nothing to watch or listen to

The sensor measures radio-channel variation instead of collecting audiovisual content.

02

Detection happens on-device

Normal sensing frontends publish derived motion state and telemetry, not raw CSI.

03

Raw collection is explicit

CSI leaves the device only when you deliberately run the separate Streamer workflow.

TWO PROFILES · ONE LOCAL RUNTIME

Choose what your product needs.

Both profiles run entirely on the ESP32. The choice is how to spend the device’s CPU, memory, startup time, and detection-quality budget.

01Resource headroom

Lightweight Detection

Reserve more CPU time and working memory for connectivity, UI, Matter, OTA, or the rest of your product.

  • Lower active detector cost
  • Quiet startup calibration
  • No training data required
Compare profiles →
02Detection quality

High-Accuracy Detection

Spend more feature state and inference work on stronger accuracy and generalization across the maintained corpus.

  • Higher validated accuracy
  • No threshold calibration
  • Open trained model
