On-device Wi-Fi sensing

Sense motion with
the Wi-Fi already there.

ESPectre measures how the Wi-Fi channel changes as people move through a room. Processing runs locally on one supported ESP32.
No cameras, microphones, or cloud processing.

Motion, not media

Motion without
images or audio.

ESPectre derives motion from changes in the Wi-Fi channel. It does not collect images or audio, which makes the sensing boundary easier to explain in shared spaces such as schools, gyms, offices, public venues, and places of worship. See how it works →

Built to embed

Add local motion sensing
to your product.

ESPectre’s shared C++ core adds local motion sensing to ESP32 products without cameras or dedicated radar hardware. OEMs can choose Lightweight Detection when CPU and working memory are tight, or High-Accuracy Detection when detection quality is the priority.
