## Validation rule

Per-file integrity and signal-quality checks cover `empty`, `static_presence`, `motion`, and `test`.

A pair is considered valid when:

- labels are coherent (`static_presence` vs `motion`)
- replaying the production `ClassicDetector` with a threshold calibrated from the pair `static_presence` capture keeps `static_presence` mostly idle
- `static_presence` above-threshold share <= 5%, `motion` above-threshold share >= 95%, and the motion-minus-static gap >= 90%

Empty sanity uses overlapping `static_presence` groups with the same 
chip/environment to check both quietness and separability, after dropping 
reference frames from `empty` files when present.

Computed metrics:

- `Threshold`: pair-specific classic runtime threshold calibrated from `static_presence`
- `Static Above`: share of replayed classic windows classified as motion on `static_presence`
- `Motion Above`: share of replayed classic windows classified as motion on `motion`
- `Motion Peak`: maximum replayed classic primary score divided by the threshold
- `Empty separation`: score-based separability between `empty` and 
  `static_presence` windows using `z(turb_mean)`
- `Gap`: non-negative time between the `static_presence` and `motion` capture intervals
  regardless of acquisition order (`0s` means the intervals overlap)
- `Subcarriers`: `DEFAULT_SUBCARRIERS` = fixed production default set
- `Turbulence`: `CV` = coefficient of variation (`std/mean`), the shared production path for the variance baseline and ML
